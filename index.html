Проверка себя

Приложение проверяет только публичные/разрешённые источники и локальный Telegram-экспорт. Оно не ломает сервисы и не пытается получить чужие приватные данные.

Telegram export

Для поиска своих упоминаний в Telegram сделай официальный экспорт: Telegram Desktop → Настройки → Продвинутые → Экспорт данных → Machine-readable JSON. Затем выбери здесь файл result.json.
